# TD STAPS – Plateforme interactive (L1)

Plateforme web interactive pour les TD de **Sciences de l’ingénieur – L1 STAPS LASSR**.  
Déployée via **GitHub Pages**.

🔗 Accès direct :  
https://yannasse42.github.io/TD/

---

## 📚 Contenu

### 🎾 TD 1.1 – Service au tennis (Bac 2022)
- Modélisation d’un service « à plat »
- Trajectoire dans un plan vertical
- Validation du franchissement du filet
- Étude des vitesses minimales et maximales
- Version modèle scolaire + version réaliste (drag & effet Magnus)

### 🏀 TD 1.2 – Lancer franc basket (Bac 2024)
- Mouvement parabolique
- Équations horaires
- Condition d’entrée dans l’arceau
- Simulateur interactif
- Étude énergétique (rebond, pertes)

---

## 🧠 Objectifs pédagogiques

- Manipuler les équations du mouvement
- Relier modèle mathématique et réalité sportive
- Interpréter graphiquement une trajectoire
- Comprendre les limites d’un modèle simplifié

---

## 👨‍🏫 Mode enseignant

Les corrections détaillées peuvent être verrouillées par un code d’accès intégré dans chaque TD.

---

## ⚙️ Technologies utilisées

- HTML / CSS / JavaScript pur
- Canvas API (simulations)
- MathJax (affichage LaTeX)
- GitHub Pages (hébergement)

---

## 📱 Compatibilité

- Fonctionne sur ordinateur, tablette et smartphone
- Aucun téléchargement requis
- 100% navigateur
